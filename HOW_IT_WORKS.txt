1. SYSTEM OVERVIEW & ARCHITECTURE
================================================================================

The Swar Sadhana Web Application is built as a Client-Server full-stack web application:

[ Client (React SPA) ]  <--- HTTP / REST API (Port 5000) --->  [ Backend (Express Server) ]
       |                                                               |
  React State & UI                                         +-----------+-----------+
  - Page Navigation                                        |                       |
  - Audio Player                                      [ MongoDB ]            [ Nodemailer ]
  - Lightbox / Modals                               (Database Storage)      (Email Transport)
  - Interactive Galleries

- Client: Single Page Application (SPA) built with React (v19) running on port 3000 during development.
- Server: RESTful API built with Node.js & Express running on port 5000.
- Database: MongoDB via Mongoose ORM for storing student inquiries.
- Mail Service: Nodemailer transport service sending real-time notification emails to academy management.

3. FRONTEND DEEP-DIVE (client/src/App.js & styles.css)
================================================================================

A. Navigation & Page Routing:
   - The application acts as a Single Page Application using React state:
     `const [currentPage, setCurrentPage] = useState("home");`
   - Navigation links update `currentPage` to render views conditionally:
     - "home"         -> Hero Slider, Academy Legacy, Founders, Quick Intro, Contact Section
     - "student-life" -> Student Life & Riyaz Page (Classroom, Riyaz, Festival Grid, Lightbox)
     - "events"       -> Upcoming Announcements, Past Events Grid, Event Modal & Event Galleries
     - "courses"      -> Vocal Music Courses breakdown
     - "recognition"  -> Bangiya Sangeet Parishad certifications & awards
     - "contact"      -> Full Enquiry Form Section
   - Navigation automatically scrolls to top on page change using a React `useEffect` hook.

B. Interactive Hero Slider:
   - State `activeSlide` tracks index (0, 1, 2) in `slidesData`.
   - A 5-second `setInterval` automatically advances slides.
   - Manual next/previous arrow buttons and slide dot indicators allow direct navigation.

C. Audio Player Component:
   - Utilizes React `useRef(null)` bound to an HTML5 `<audio>` element (`omAudio`).
   - Toggling the audio button calls `.play()` or `.pause()` on the ref and updates `isAudioPlaying` state to switch play/pause icons.

D. Scroll Animations (`useSLFadeIn` Custom Hook):
   - Uses the browser's `IntersectionObserver` API to detect when sections enter the viewport.
   - Dynamically adds the `.is-visible` CSS class to trigger CSS fade-in & slide-up transitions.

E. Modals & Lightboxes:
   - Lightbox state (`lightboxImg`): Displays an enlarged overlay image when clicking any photo in galleries.
   - Event Modal state (`selectedEvent`): Opens a pop-up modal showing detailed event descriptions, date, time, venue, and bulleted highlights.
   - Event Gallery State (`activeGalleryEvent`): Replaces the events list view with a dedicated grid of high-resolution photos for that specific event.

4. BACKEND DEEP-DIVE (server/index.js)
================================================================================

A. Server Setup & Middleware:
   - Instantiates Express app on port `process.env.PORT || 5000`.
   - Uses `cors()` to allow cross-origin requests from the React frontend.
   - Uses `express.json()` to parse incoming JSON request payloads.

B. Database Connection (MongoDB):
   - Connects to MongoDB via Mongoose if `process.env.MONGO_URI` is present.
   - Defines Mongoose schema `enquirySchema`:
     ```javascript
     {
       name: String,
       email: String,
       phone: String,
       message: String,
       timestamps: true // Automatically adds createdAt and updatedAt
     }
     ```

C. Email Service Configuration (Nodemailer):
   - Reads `EMAIL_USER`, `EMAIL_PASS`, and `CONTACT_RECIPIENT` from environment variables.
   - Creates Nodemailer SMTP transport service.
   - If credentials are not set, logs a warning and degrades gracefully without crashing.

D. REST API Endpoints:
   1. GET `/`
      - Health check endpoint returning plain text: `"Swar Sadhana API is running"`.

   2. POST `/api/enquiry`
      - Accepts JSON payload: `{ name, email, phone, message }`.
      - Validates that `name`, `email`, and `message` are non-empty. Returns 400 Bad Request if validation fails.
      - Saves enquiry record to MongoDB database via `Enquiry.create(...)`.
      - Sends an automated notification email via `transporter.sendMail(...)` formatted with name, email, phone, and message body.
      - Returns JSON `{ success: true }` to frontend.

5. STEP-BY-STEP DATA FLOW (ENQUIRY FORM LIFECYCLE)
================================================================================

Here is what happens when a user submits the Contact / Enquiry form:

1. [USER ACTION]: User fills in Name, Email, Phone Number, Message and clicks "Send Message".
2. [REACT STATE]: `handleFormSubmit` event handler in `App.js` fires.
3. [VALIDATION]: React checks form inputs and sets status state: `setFormStatus({ type: "sending", message: "Sending..." })`.
4. [HTTP REQUEST]: React executes `fetch("/api/enquiry", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(formData) })`.
   - In development, CRA Proxy proxies `/api/enquiry` to `http://localhost:5000/api/enquiry`.
5. [EXPRESS RECEIVE]: Server receives POST request at `/api/enquiry`.
6. [DATABASE WRITE]: Express inserts document into MongoDB `enquiries` collection via Mongoose `Enquiry.create(...)`.
7. [EMAIL TRIGGER]: Express calls `transporter.sendMail()` to deliver email notification to academy inbox.
8. [HTTP RESPONSE]: Express responds with HTTP 200 JSON `{ success: true }`.
9. [UI UPDATE]: React receives response, clears form input fields, and displays green success alert banner:
   "Thank you for contacting Swar Sadhana! We have received your message and will get back to you soon."

7. HOW TO RUN THE PROJECT LOCALLY
================================================================================

1. Start Backend Server:
   - Navigate to `server/` directory: `cd server`
   - Run: `npm start`
   - Output: `Swar Sadhana server listening on port 5000`

2. Start Frontend React Client:
   - Navigate to `client/` directory: `cd client`
   - Run: `npm start`
   - Application opens automatically at `http://localhost:3000`

3. Production Build:
   - Inside `client/` directory, run: `npm run build`
   - Optimized build generated in `client/build/`.
